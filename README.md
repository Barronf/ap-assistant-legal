## About AP Assistant

AP Assistant automates accounts payable intake and posting for QuickBooks Online
company files, connecting through the Intuit API. It reads and writes accounting
records — chart of accounts, journal entries, transactions, and vendor and customer
records — on company files the client has explicitly authorised.

The Application is used by Ferguson CPA in the course of providing accounting
services to clients. It is not distributed publicly and is not listed on the
Intuit App Store.

## This repository

This repository contains only the published legal documents for the Application,
hosted via GitHub Pages so the URLs can be supplied to Intuit. It contains no
application source code.
